# MHN Hunter Assistant

Monster Hunter Now 個人狩獵助手。

## V0.2

- 手機優先介面
- 我的獵人資料（名稱 / HR / 主武器）
- 我的裝備資料庫
- 裝備部位、Grade、Level、屬性與備註
- 裝備篩選與刪除
- 素材升級計畫
- 目前等級 → 目標等級
- 每種素材的「需要 / 已有 / 尚缺」
- 素材完成率與總缺口統計
- 可直接更新目前持有數量
- 本機儲存（localStorage）
- JSON 備份匯出 / 匯入
- PWA 與離線快取

## Roadmap

- V0.2.x MHN 實際升級素材資料，自動帶入需求
- V0.3 配裝推薦
- V0.4 魔物資料與弱點
- V0.5 截圖匯入

> 本專案為玩家自用工具，與 Niantic / Capcom 無官方關聯。
